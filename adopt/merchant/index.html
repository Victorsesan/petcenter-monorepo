Bot Profile

A single automated identity that sends your pre-written responses when a visitor starts a chat about one of your listings, or reopens a closed one. It never replies live — only these structured messages.

In any message below, type {name} anywhere you'd say the visitor's name — it's replaced with their real first name right before the message is sent.
The four reasons below are carried over unchanged from the super admin's own bot panel (adoption inquiry / shipping / health / general) as the literal clone source. This project's own enquiry-reason taxonomy for messaging a merchant about a listing isn't defined anywhere in the current SHARED CONTRACTS — reconcile this list once Task D1 or C5 (whichever ends up owning the enquiry form) publishes the real reason set.

Scenario A — When a chat starts

Sent once, the moment a visitor picks a reason and starts a brand-new chat about one of your listings. One message per reason, plus a fallback used only if a reason has no message set below.

After the visitor's first message

Sent once, right after the visitor sends their very first message in a brand-new chat. One single message for every reason — not per-reason, since this just acknowledges that they've been heard.

Scenario B — When a closed chat is re-opened

These only fire if the visitor goes back to the start screen and picks a different reason than the one their closed chat originally had. If they just keep typing into the same reopened chat without picking a new reason, none of these fire.

Scenario B — visitor's first message

Sent once, right after the visitor's message that reopened their closed chat — fires every time, regardless of whether they picked a new reason above. Separate from Scenario A's version above; the two can't share the same text.
