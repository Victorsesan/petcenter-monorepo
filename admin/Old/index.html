Bot Profile

A single automated identity that sends pre-written responses when a chat starts or when a closed ticket is re-opened. It never replies live — only these structured messages.

In any message below, type {name} anywhere you'd say the customer's name — it's automatically replaced with the real first name they entered before the message is sent. Example: "Hi {name}, welcome to the live chat!" becomes "Hi Sarah, welcome to the live chat!" for a customer named Sarah.
PB

Scenario A — When a chat starts

Sent once, the moment a customer picks a reason and starts a brand-new chat. One message per reason, plus a fallback used only if a reason has no message set below.

After the customer's first message

Sent once, right after the customer sends their very first message in a brand-new chat (after they've had a chance to explain their issue). One single message for every reason — not per-reason, since this just acknowledges that they've been heard.

Scenario B — When a closed chat is re-opened

The messages below only fire if the customer goes back to the start screen and picks a different reason than the one their closed chat originally had — based on that thread's original reason, not whatever they're asking now. If they just keep typing into the same reopened chat without picking a new reason, none of these fire.

Scenario B — customer's first message

Sent once, right after the customer's message that reopened their closed chat — fires every time a chat is reopened this way, regardless of whether they picked a new reason above. This is a separate message from Scenario A's version above; they can't share the same text.
