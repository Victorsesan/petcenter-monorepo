# Historical Completion Evidence

This folder preserves the completion and handoff documents from the original worker archive. They are read-only historical evidence. They describe what a previous worker attempted, the files they claimed to touch, known bugs, and where they stopped; they do not prove that the current GitHub source contains the claimed implementation.

Every Manus account must read the files matching its own project and task numbers after completing `CORE-DOCUMENT-READING-GATE.md` and before opening application source. Compare each document with the original task tracker, `main`, every relevant worker branch, the account report, and the current files. Preserve the evidence path and the comparison result in the account report.

The imported documents are grouped under the worker-package name from the original archive. Two archive packages did not contain a completion document; those gaps remain explicitly recorded in `WORKER-PACKAGE-INVENTORY.md`. A missing document is an evidence gap, not permission to stop independently verifiable work or invent an undocumented contract.

The historical documents may contain old delivery instructions that conflict with the current Git-aware workflow. The current Worker and VDM protocols and `CORE-DOCUMENT-READING-GATE.md` govern repository delivery. Historical Integrator instructions remain useful for evidence comparison, shared-file reconciliation, and bug triage, but their manual-upload/no-GitHub workflow is superseded.
